# Critique Decisions

After each open layer, choose exactly one:

| Decision | When |
|----------|------|
| `accept` | Metrics + vision + features pass; advance layer |
| `replan` | Blueprint wrong or shallow — edit JSON, re-validate |
| `recode` | Blueprint OK, factory wrong — edit TypeScript / re-cast |
| `ask` | Need another view, crop, or hybrid permission |
| `abort` | Not feasible with available evidence |

Root-cause: if silhouette is wrong, prefer `replan`/`fit` before endless material tweaks.
